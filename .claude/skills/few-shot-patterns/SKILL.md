# Few-Shot Patterns

> Parte del plugin [`prompt-architecture`](../../plugins/prompt-architecture.md) — [Owl-Listener/ai-design-skills](https://github.com/Owl-Listener/ai-design-skills)

Diseña los ejemplos de entrada/salida que se incluyen dentro de un prompt para que la IA
replique un patrón, en vez de depender solo de instrucciones descritas en palabras — a
veces mostrar 2-3 ejemplos bien elegidos orienta el comportamiento mucho mejor que explicar
la regla de forma abstracta.

## Cuándo se activa

Describir el resultado esperado en palabras no es suficiente (la IA lo interpreta de forma
distinta a la esperada cada vez) y hace falta mostrar ejemplos concretos para fijar el
patrón deseado.
